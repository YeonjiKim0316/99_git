# git stash : 임시저장 
- 브랜치에 다른 브랜치로 넘어갈 때 임시저장(commit은 되지 않음)
- git stash list로 보고 git stash pop 으로 꺼내옵니다.
- 충돌이 나면 비교해서 그 중에 원하는 것을 선택합니다.
- git add .
- git commit -m "fix: 수정내용"
- git push origin 브랜치명
